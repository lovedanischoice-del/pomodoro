# 🔍 Google 로그인 문제 진단

## 현재 상태
✅ 네비게이션 정상 작동  
✅ Settings 화면 전환 성공  
⚠️ Google 로그인 버튼 클릭 시 팝업 안 뜸

---

## 🧪 Console에서 테스트

브라우저에서 **F12** → **Console** 탭에서 다음 명령어를 입력하세요:

### 1. 로그인 버튼 확인
```javascript
document.getElementById('googleLoginBtn')
```
**예상 결과**: `<button id="googleLoginBtn" ...>` 표시  
**만약 `null`이면**: 버튼이 HTML에 없거나 ID가 잘못됨

### 2. googleLogin 함수 확인
```javascript
typeof googleLogin
```
**예상 결과**: `"function"`  
**만약 `"undefined"`이면**: firebase-config.js가 로드되지 않음

### 3. Firebase Auth 확인
```javascript
typeof firebase
```
**예상 결과**: `"object"`  
**만약 `"undefined"`이면**: Firebase SDK가 로드되지 않음

### 4. 수동으로 로그인 시도
```javascript
googleLogin()
```
**예상 결과**: Google 로그인 팝업이 열림  
**에러 발생 시**: 에러 메시지를 알려주세요

## 🐛 예상 문제 및 해결

### 문제 1: "googleLogin is not defined"
**원인**: firebase-config.js가 로드되지 않음  
**해결**: 
```javascript
// Network 탭에서 firebase-config.js 확인
// 빨간색이면 파일 경로 문제
```

### 문제 2: "auth/popup-blocked"
**원인**: 브라우저가 팝업 차단  
**해결**: 
- 주소창 오른쪽 팝업 차단 아이콘 클릭
- "항상 허용" 선택

### 문제 3: "auth/unauthorized-domain"
**원인**: Firebase에서 localhost 승인 안 됨  
**해결**: 
1. Firebase Console → Authentication → Settings
2. Authorized domains에 `localhost` 추가

### 문제 4: "Cannot read property 'GoogleAuthProvider' of undefined"
**원인**: Firebase SDK 로드 실패  
**해결**: 
- Network 탭에서 Firebase SDK 파일 확인
- 인터넷 연결 확인
