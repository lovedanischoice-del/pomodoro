## 🎯 프로젝트 개요

### 앱 이름
**Bbangmodoro** 🐧

### 설명
장작 타는 소리와 함께하는 몰입형 포모도로 타이머 앱

### 주요 특징
- **포모도로 타이머**: 20분 집중 + 5분 휴식
- **몰입 배경음**: 장작 타는 소리 (작업 시간에만 재생)
- **할 일 관리**: 로컬 저장 기반 투두 리스트
- **통계 기능**: 주간/월간 집중 시간 시각화
- **PWA 지원**: 오프라인 작동 가능
- **안드로이드 앱**: Capacitor로 네이티브 앱 변환 가능

## 🛠️ 기술 스택

### 프론트엔드
- **HTML5**: 시맨틱 마크업
- **CSS3**: 
  - Vanilla CSS (커스텀 디자인)
  - CSS Variables (테마 관리)

  - 모듈 패턴
  - 클래스 기반 설계 (StatsManager)
  - LocalStorage API
  - Service Worker API

### PWA (Progressive Web App)
- **Service Worker**: 오프라인 캐싱
- **Web App Manifest**: 홈 화면 설치
- **Notification API**: 알림 기능

### 모바일 앱
- **Capacitor 8.x**: 웹 → 네이티브 앱 변환
- **Android SDK**: 안드로이드 앱 빌드

### 폰트
- **Google Fonts**:
  - Inter (300, 400, 600)
  - Outfit (300, 500, 700, 800)

### 5️⃣ **service-worker.js** (60줄)

#### PWA 캐싱 전략
```javascript
const CACHE_NAME = 'bbangmodoro-v1';
const urlsToCache = [
  '/',
  '/index.html',
  '/style.css',
  '/main.js',
  '/fire.mp3',
  'https://fonts.googleapis.com/...'
];

// 1. 설치 시 캐시 생성
self.addEventListener('install', event => {
  caches.open(CACHE_NAME).then(cache => {
    cache.addAll(urlsToCache);
  });
});

// 2. 활성화 시 오래된 캐시 삭제
self.addEventListener('activate', event => {
  caches.keys().then(cacheNames => {
    cacheNames.forEach(cacheName => {
      if (cacheName !== CACHE_NAME) {
        caches.delete(cacheName);
      }
    });
  });
});

// 3. Fetch 시 네트워크 우선, 캐시 폴백
self.addEventListener('fetch', event => {
  fetch(event.request)
    .then(response => {
      // 성공 시 캐시에 저장
      cache.put(event.request, response.clone());
      return response;
    })
    .catch(() => {
      // 실패 시 캐시에서 가져오기
      return caches.match(event.request);
    });
});
```

    ↓
    localStorage.setItem('focusSessions', ...)
    ↓

```
[Timer View]
  todoInput 입력 → addTodo()

    ↓
    renderTodos() → Timer View 업데이트

[Tasks View]
  todoInputTasks 입력 → addTaskFromTasksView()
    ↓
    같은 todos 배열 사용
    ↓

    ↓

### 3. 네비게이션 전환 시

```

## 🐛 알려진 이슈

### 1. Service Worker 캐시 문제
- **증상**: 파일 수정 후 변경사항 미반영
- **해결**: 개발자 도구 → Application → Service Workers → Unregister

### 2. 안드로이드 빌드 오류
- **증상**: Gradle 동기화 실패
- **해결**: `cd android && ./gradlew clean && cd .. && npm run sync`

### 3. 알림 권한
- **증상**: 알림이 표시되지 않음
- **해결**: 브라우저 설정에서 알림 권한 허용
