## 🐛 문제 해결

### 문제 1: "This app is not verified" 경고
**원인**: Firebase 프로젝트가 Google 검증을 받지 않음  
**해결**: 
- 개발/테스트 단계에서는 **"Advanced"** → **"Go to [프로젝트명] (unsafe)"** 클릭
- 프로덕션 배포 시에는 Google OAuth 검증 신청 필요

### 문제 2: "Popup blocked" 오류
**원인**: 브라우저가 팝업을 차단함  
**해결**: 
- 브라우저 주소창 오른쪽의 팝업 차단 아이콘 클릭
- "항상 허용" 선택

### 문제 3: "auth/unauthorized-domain" 오류
**원인**: localhost가 승인된 도메인에 없음  
**해결**: 
1. Firebase Console → Authentication → Settings
2. Authorized domains에 `localhost` 추가

### 문제 4: 로그인 후 데이터가 동기화되지 않음
**원인**: Firestore 규칙 설정 필요  
**해결**: 
1. Firebase Console → Firestore Database
2. Rules 탭
3. 다음 규칙 추가:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```
