# 🔍 빌드 타임스탬프 디버깅 가이드

## Console에서 확인할 사항

브라우저에서 **F12** → **Console** 탭에서 다음 명령어를 순서대로 입력하세요:

### 1. 요소 확인
```javascript
document.getElementById('buildTimestamp')
```
**예상 결과**: `<p id="buildTimestamp">Updated: Loading...</p>`  
**만약 `null`이면**: HTML 요소가 없거나 ID가 잘못됨

### 2. Settings 화면 확인
```javascript
document.getElementById('settingsView')
```
**예상 결과**: `<main id="settingsView" class="view">...</main>`  
**만약 `null`이면**: Settings 화면이 로드되지 않음

### 3. 함수 존재 확인
```javascript
typeof updateBuildTimestamp
```
**예상 결과**: `"function"`  
**만약 `"undefined"`이면**: tasks-settings.js가 로드되지 않음

### 4. 수동으로 함수 실행
```javascript
updateBuildTimestamp()
```
**예상 결과**: Console에 "Build timestamp updated: Updated: 2026. 02. 07 12:59" 표시  
**만약 에러 발생**: 에러 메시지 확인

### 5. initSettings 확인
```javascript
typeof initSettings
```
**예상 결과**: `"function"`  
**만약 `"undefined"`이면**: tasks-settings.js 로드 실패

### 6. Settings 화면으로 이동
```javascript
document.querySelector('[data-view="settingsView"]').click()
```
**예상 결과**: Settings 화면으로 전환

### 7. 다시 타임스탬프 확인
```javascript
document.getElementById('buildTimestamp').textContent
```
**예상 결과**: "Updated: 2026. 02. 07 12:59"  
**만약 "Updated: Loading..."**: 함수가 실행되지 않음

## 🐛 예상 문제

### 문제 1: tasks-settings.js 로드 실패
**확인**: Network 탭에서 `tasks-settings.js` 확인  
**해결**: 파일 경로 확인, 강력 새로고침

### 문제 2: Settings 화면에 가지 않음
**확인**: 현재 어떤 화면인지 확인
```javascript
document.querySelector('.view.active').id
```
**해결**: Settings 탭 클릭 후 다시 확인

### 문제 3: DOMContentLoaded 타이밍 문제
**확인**: 온보딩 화면 상태
```javascript
document.getElementById('app').classList.contains('app-hidden')
```
**해결**: 온보딩 완료 후 다시 확인
