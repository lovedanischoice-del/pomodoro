# 동기화 및 로그인 기능 가이드

현재 Bbangmodoro 앱은 사용자의 데이터를 브라우저의 **로컬 스토리지(Local Storage)**에 저장하고 있습니다. 이는 인터넷 연결 없이도 빠르게 작동하는 장점이 있지만, 다음과 같은 특징이 있습니다:

1.  **기기에 귀속됨**: 핸드폰에서 작성한 데이터는 핸드폰에만, 컴퓨터에서 작성한 데이터는 컴퓨터에만 저장됩니다.
2.  **동기화 안 됨**: 별도의 서버가 없으므로 자동으로 기기 간 데이터가 이동하지 않습니다.

## 해결 방법 1: 데이터 백업/복구 (현재 기능)
설정(Settings) 탭에 있는 **Data** 섹션을 활용하세요.

1.  **Export Data (내보내기)**: 현재 기기의 데이터를 파일(`.json`)로 저장합니다. 이 파일을 카카오톡 나에게 보내기나 이메일 등을 통해 다른 기기로 전송하세요.
2.  **Import Data (가져오기)**: 다른 기기에서 받은 파일을 선택하여 데이터를 덮어씌웁니다.

## 해결 방법 2: 로그인 기능 추가 (권장: Firebase)
앱을 더욱 발전시켜 자동 동기화를 원하신다면 **Firebase**와 같은 BaaS(Backend-as-a-Service)를 연동하는 것이 좋습니다.

### 장점
*   구글 로그인 등 간편한 인증 구현
*   실시간 데이터 동기화 (폰에서 체크하면 컴퓨터에도 바로 반영)
*   데이터 손실 방지

### 구현 방법 (개발자용)
1.  Firebase 프로젝트 생성
2.  `init.js` 등에서 Firebase SDK 초기화
3.  `localStorage` 저장 로직을 `Firestore` 저장 로직으로 변경
4.  로그인 버튼 추가

이 기능 구현을 원하시면 말씀해 주세요! 프로토타입 코드를 작성해 드릴 수 있습니다.
