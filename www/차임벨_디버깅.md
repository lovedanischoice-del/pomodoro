# 🔔 차임벨 소리 디버깅 가이드

## Console에서 테스트

브라우저에서 **F12** → **Console** 탭에서 다음 명령어를 순서대로 입력하세요:

### 1. 파일 경로 테스트
```javascript
// 오디오 파일 로드 테스트
const testAudio = new Audio('./chime.mp3');
testAudio.play().then(() => {
    console.log('✅ 차임벨 재생 성공!');
}).catch(error => {
    console.error('❌ 차임벨 재생 실패:', error);
});
```

### 2. playChimeBell 함수 확인
```javascript
typeof playChimeBell
```
**예상 결과**: `"function"`  
**만약 `"undefined"`이면**: main.js가 로드되지 않음

### 3. 직접 함수 실행
```javascript
playChimeBell()
```
**예상 결과**: 차임벨 소리 재생  
**에러 발생 시**: 에러 메시지 확인

### 4. Settings 화면 확인
```javascript
document.getElementById('notificationSound')
```
**예상 결과**: `<input type="checkbox" ...>`  
**만약 `null`이면**: Settings 화면이 로드되지 않음

### 5. Network 탭 확인
1. **F12** → **Network** 탭
2. 페이지 새로고침 (Ctrl + Shift + R)
3. `chime.mp3` 검색
4. **상태 코드 확인**:
   - ✅ **200**: 파일 로드 성공
   - ❌ **404**: 파일을 찾을 수 없음
   - ❌ **CORS**: 보안 문제

## 🐛 예상 문제 및 해결

### 문제 1: 404 Not Found
**원인**: chime.mp3 파일이 없거나 경로가 잘못됨  
**해결**:
```powershell
# PowerShell에서 확인
Test-Path "e:\바이브코딩\pomodoro\chime.mp3"
```

### 문제 2: CORS 에러
**원인**: file:// 프로토콜로 접근  
**해결**: 
```powershell
# HTTP 서버 실행
cd e:\바이브코딩\pomodoro
python -m http.server 8000
```
그 다음 `http://localhost:8000` 접속

### 문제 3: "play() failed because the user didn't interact"
**원인**: 브라우저 자동 재생 정책  
**해결**: 
- 페이지를 클릭한 후 다시 시도
- Settings 탭에서 토글을 직접 클릭

### 문제 4: 파일 형식 문제
**원인**: chime.mp3 파일이 손상됨  
**해결**:
```powershell
# 파일 크기 확인
Get-Item "e:\바이브코딩\pomodoro\chime.mp3" | Select-Object Length
```
0 바이트면 파일이 손상된 것

### 문제 5: 볼륨이 0
**원인**: 시스템 볼륨이나 브라우저 볼륨이 음소거  
**해결**:
```javascript
// Console에서 볼륨 확인
const audio = new Audio('./chime.mp3');
audio.volume = 1.0;  // 최대 볼륨
audio.play();
```

## 🔧 수동 테스트

### 방법 1: Console에서 직접 재생
```javascript
const chime = new Audio('./chime.mp3');
chime.volume = 1.0;
chime.play();
```

### 방법 2: HTML에서 직접 재생
1. **F12** → **Elements** 탭
2. `<body>` 태그 찾기
3. 우클릭 → **Edit as HTML**
4. 다음 코드 추가:
```html
<audio controls>
    <source src="chime.mp3" type="audio/mpeg">
</audio>
```
5. 재생 버튼 클릭
